🛒 Amazon Sales Analysis
This project contains a data analysis and visualization notebook focusing on Amazon sales data.

🚀 Technologies Used
Python
Pandas (Data manipulation & cleaning)
Seaborn & Matplotlib (Data visualization)
Jupyter Notebook

📊 What's Inside
Loading and cleaning the Amazon sales dataset.
Exploring data features and handling missing values.
Generating insightful visual plots using Seaborn (sns.set_theme(style="whitegrid")).
Drawing conclusions from sales trends and metrics.

🛠️ How to View
You can directly open the amazon-sales-analysis.ipynb file here on GitHub to see the code, outputs, and visualizations.
